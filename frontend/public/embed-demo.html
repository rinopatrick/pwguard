PWGuard Widget Demo

This page demonstrates the embeddable password strength widget.

How to embed

Add this single line before </body>:

<script src="https://your-domain.com/widget.js"
  data-api-url="https://your-domain.com"
  data-theme="dark"
  data-position="below"></script>

Options:

  • data-api-url — PWGuard server URL
  • data-theme — dark or light
  • data-position — below or inline
